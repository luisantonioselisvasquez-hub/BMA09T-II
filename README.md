# Grupo 1: Árboles AVL y árboles rojo-negro

- **Concepto de árboles balanceados:** Definición de los árboles de búsqueda balanceados y explicación de la importancia de mantener una altura controlada.
- **Árboles AVL:** Explicación de sus propiedades, del factor de equilibrio y de las condiciones que debe cumplir cada nodo.
- **Rotaciones:** Explicación de las rotaciones simples y dobles utilizadas para recuperar el equilibrio de un árbol AVL.
- **Inserción y eliminación en árboles AVL:** Análisis de las operaciones y de los reajustes necesarios para mantener el balance.
- **Árboles rojo-negro:** Explicación de sus propiedades, reglas de coloración y restricciones estructurales.
- **Balanceo en árboles rojo-negro:** Explicación de las recoloraciones y rotaciones utilizadas durante las operaciones.
- **Comparación entre AVL y rojo-negro:** Análisis de sus diferencias estructurales, complejidades y aplicaciones.
- **Aplicaciones:** Presentación de aplicaciones de los árboles AVL y rojo-negro en índices ordenados, diccionarios, conjuntos ordenados y sistemas que requieren búsquedas, inserciones y eliminaciones eficientes.
